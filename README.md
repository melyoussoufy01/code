# Houser

Houser est un chasseur immobilier locatif personnel pour Strasbourg et sa première couronne.

## Règles principales
- Bien vendu libre uniquement
- Financement Mourabaha
- Apport cible : ~25 k€
- Cash-flow neutre/positif idéal
- Effort mensuel >100 € accepté seulement pour un actif très qualitatif
- Charges de copropriété fortement pénalisées si élevées
- DPE F/G exclus
- Meilleurs matches affichés en premier
- Houser Price expliqué par rendement cible, valeur de marché et ajustements de risque
- Mode `Creuser` avec offre d'ouverture, prix cible et faisabilité de la négociation

## Lancer localement
Le prototype est une application statique autonome. Ouvrir simplement `index.html` dans un navigateur.

## Publication
Le workflow GitHub Pages de `.github/workflows/pages.yml` publie le site statique depuis le dépôt.
